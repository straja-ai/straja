OpenClaw Integration Quickstart

Keep OpenClaw as orchestrator. Use Vault MCP tool calls as the policy-enforced data boundary. 

export STRAJAD_AUTH_TOKEN="replace-me"
export STRAJAD_GOOGLE_OAUTH_CLIENT_ID="google-client-id"
export STRAJAD_GOOGLE_OAUTH_CLIENT_SECRET="google-client-secret"
export STRAJAD_GOOGLE_OAUTH_REDIRECT_URL="http://127.0.0.1:8787/vault/api/drive/oauth/callback"
export STRAJAD_MAX_INGEST_BYTES="8388608"
export STRAJAD_BROKER_ENABLED=true
export STRAJAD_BROKER_MODEL="phi4-mini:3.8b"
./bin/strajad --broker-install-model --broker-model phi4-mini:3.8b
./bin/strajad
